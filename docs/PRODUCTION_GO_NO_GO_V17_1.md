# V17.1 Production Go / No-Go

## NO-GO until all of the following are evidenced

- [ ] CNDP formalities/authorization applicable to health-data processing completed.
- [ ] International transfers assessed and formalities completed where applicable.
- [ ] Final legal notices/CGU/CGV/privacy approved.
- [ ] Real provider contracts and subprocessor list approved.
- [ ] Supabase production configuration reviewed.
- [ ] MFA for privileged users.
- [ ] Distributed rate limiting/WAF.
- [ ] Malware scanning for medical documents.
- [ ] Staging E2E and RLS tests pass.
- [ ] External pentest/DAST completed and critical/high issues closed or formally accepted.
- [ ] Backup restoration drill passes.
- [ ] Incident response drill completed.
- [ ] Telemedicine legal/clinical review completed if enabled.
- [ ] Payment provider certification/testing completed if enabled.

A green software build alone is insufficient for a production healthcare launch.
