# Compliance worklist

This is an engineering checklist, not legal advice or certification.

- [ ] Identify Moroccan healthcare/privacy obligations applicable to Tabib.ma and each processing activity.
- [ ] Map data categories, purposes, recipients, retention and deletion rules.
- [ ] Define patient rights workflows: access, correction, deletion where legally applicable, export and consent/withdrawal.
- [ ] Establish controller/processor roles and contracts with every provider.
- [ ] Review hosting, data residency and international transfers.
- [ ] Perform DPIA/privacy impact assessment where required.
- [ ] Establish incident response, breach assessment and notification procedures.
- [ ] Define backup retention and secure deletion.
- [ ] Complete independent penetration test and remediation.
- [ ] Validate encryption, key management, MFA and privileged-access controls in production.
- [ ] Validate document malware scanning/quarantine before allowing `available` status.
- [ ] Obtain legal and clinical governance sign-off before real patient data.
