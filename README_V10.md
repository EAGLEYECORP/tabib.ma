# Tabib.ma — V10

V10 ajoute la gestion multi-établissements : cliniques, équipes, rôles, sites et salles, avec isolation tenant par Supabase RLS.

Stack conservée : Next.js + TypeScript + Supabase + Vercel.

Cette version conserve les modules V6–V9. Appliquer `schema_v10_clinics.sql` après les migrations précédentes.

V10 n'est pas une certification de sécurité ou de conformité médicale. Réaliser audit, pentest, tests RLS et validation réglementaire avant données réelles.
