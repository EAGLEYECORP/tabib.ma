# CNDP Pre-Production Checklist

- [ ] Identify data controller(s).
- [ ] Identify processors/subprocessors.
- [ ] Inventory health and non-health personal data.
- [ ] Define purposes and data minimization.
- [ ] Complete AIPD/DPIA where required.
- [ ] Prepare applicable CNDP authorization/notification files.
- [ ] Complete international-transfer assessment.
- [ ] Finalize privacy notice and patient information.
- [ ] Implement rights requests workflow.
- [ ] Define retention/deletion schedule.
- [ ] Document security measures.
- [ ] Keep evidence of approvals/formalities before enabling real patient data.
