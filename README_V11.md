# Tabib.ma V11 — National Operations & Platform Administration

V11 adds a platform-admin control plane while preserving V6–V10 foundations.

## Scope
- platform administration dashboard
- professional/clinic verification workflow
- pharmacy management
- user and appointment operational views
- payment/support operational views
- security/audit events
- suspension/reactivation workflow
- role separation and server-side authorization

## Important
This is an original clean-room implementation. It is not Doctolib code and is not a healthcare certification. Do not use real patient data until security, privacy, regulatory, backup and incident-response validation is complete.

Apply `supabase/schema_v11_admin.sql` after the previous migrations.
